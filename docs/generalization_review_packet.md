# New-candidate review packet

Read this packet before running any pilot ranking. Ten new publications are paired with two existing accounts. This is a small candidate-generalization pilot, not a test on new plants, a systematic sample or an independent population estimate.

For each pair: useful / context only / unresolved. Apply the same rule as development: useful if it helps assess the documented use through a relevant outcome or a direct comparison of plant parts or preparations. A part match alone is insufficient. A mismatch or null result can still be useful. Safety-only work that does neither is context. Missing access is unresolved, not context only.

Record your reason, source URL and section/table actually read. Do not infer methods from another publication. Record whether you previously reviewed the pair or saw rankings/assistant labels. Do not change the scope rule after seeing results.

Enter answers in data/generalization/reviews.jsonl, or send case IDs and answers in chat. Decision values: useful, context_only, unresolved. Leave inaccessible cases unresolved. Set saw_rankings_or_assistant_labels and previously_reviewed_this_pair truthfully; they start null. No answer or human-review declaration has been filled in for you.
